# 教程本地图片

38 张图片来自作者上传的《个人版部署教程》，已按原顺序保存为 `step-01.webp` 至 `step-38.webp`。

- 所有插图使用仓库内相对路径，不依赖金山文档、签名 URL、图床、GitHub Raw CDN 或外部字体。
- 截图经过人工总览和 OCR 辅助检查，账号邮箱、账户导航信息与创建 Token 页的凭据／验证命令使用不透明遮盖；不使用可逆图层或仅模糊处理。
- 图片重新编码并移除原 EXIF／XMP 等元数据；原文件、来源私有链接和 OCR 原文不提交。
- `manifest.json` 记录每张图片的 SHA-256、尺寸、体积及处理标记。下载完整仓库时可用它检查完整性。
- 单文件离线 HTML 在构建时把这些本地图片内嵌为 data URL，构建命令本身不访问网络。
- 画面属于作者提供的历史控制台截图，不保证菜单／权限／DNS 行为仍与当前一致；以更新后文字为准，不能复制截图的实际域名或账号。

如果替换图片，请先完成隐私审查，重新编码去元数据、更新 manifest，再运行 `npm run docs:build` 与测试。不要把包含真实 Token 的原始图片加入 Git 历史后才打码。
