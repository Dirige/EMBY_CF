# 两版自动 VPS 回退修正（2026-11-24）

个人版 `v6.4.9-refactor.8` 已 100% 发布，版本 ID `7c045fde-6c5e-4458-9634-cfaa333fbcef`。多人版 `v6.8.11-multi-refactor.3` 也已 100% 发布，版本 ID `82eb4768-8589-438b-beb5-a230bc560299`；详见 `MULTI-PUBLIC-ACCEPTANCE.md`，多轮同步范围见 `MULTI-SYNC-CHECKLIST.md`。仅代码更新，不改变既有线路、DNS、密码、数据库绑定、中继配置或配额。

## 行为

- 「自动」仍优先 Worker 直连，必须全局中继已启用且地址／密钥完整才生效；旧 `image` 继续按自动解释。
- GET/HEAD 遇到 401、403、451、502、503、504、521–526，或连接错误／响应头超时，允许一次 VPS 回退。
- POST 只对白名单端点 `Users/AuthenticateByName`、`Users/AuthenticateWithQuickConnect` 和 `Items/<id>/PlaybackInfo`，在明确收到 401/403/451 后允许一次回退。大小写、尾部斜杠和 `/emby` 等源站基础路径兼容。
- 上述 POST 请求体有界保存：最多 256 KiB，读取期限 5 秒；未提供 Content-Length 的白名单 POST 也必须在此边界内完整读取才可重放。超限恢复完整一次性流，不截断上传、不调用 clone/tee。其它未知长度上传仍直接流式转发。
- POST 的连接错误、超时、5xx，以及进度上报、上传、修改／删除等其它写请求，不做自动重放。
- VPS 仍返回 401/403/451、429、5xx 或 `X-Relay-Denied` 时不视作成功，保留直连错误；不会掩盖真实密码／Token／权限错误。
- 回退成功后，同一响应的重定向链继续经过 VPS。依然逐跳验证目标地址、禁止私网及 HTTPS 降级、跨域剥离凭据、保留签名 query 和 Range；不会把绑定 VPS IP 的签名地址改交客户端直连。
- 回退成功且 VPS 响应小于 400 时，优先使用 VPS 2 分钟。之后由下一次 GET/HEAD 请求占用 10 秒恢复探测租约，其它请求继续走 VPS；探测成功恢复直连，失败且 VPS 成功则重新进入冷却期。仅有写请求时不发起推测性探测。
- 冷却状态只含路由、源站 origin、入口 Host、CF colo／国家及期限，不保存账号、Token、签名 query 或响应内容。状态在 Worker 实例内维护，最多 512 条；不是跨节点永久切换，冷启动／回收后会重新直连优先。
- 优先 VPS 已不可用时，GET/HEAD 最多补一次直连，不再次循环尝试 VPS；已发出的 POST 不改发直连，以免重复执行。
- 「开」仍强制 VPS，配置不完整返回 503；「关」完全不使用 VPS。中途下载慢不重发成功的视频流。

## 多人版差异

- 多人版不增加上述逐线路三模式，继续使用原全局中继开关；地址／密钥缺失或全局关闭时，不发 VPS 请求。`fd` 原先未配置中继，本轮不复制个人版 VPS 地址或密钥。
- GET/HEAD 继续覆盖多人版原网关状态 `502/503/504/520–527/530`；安全 POST 白名单与请求体边界相同。
- VPS 冷却／恢复状态额外按线路所属用户隔离。同源站、同前缀的其他用户仍自行直连探测。
- 保留多人版独立推流 302 和 PlaybackInfo 映射；VPS 成功后将偏好传给匹配的推流 Host，下一次媒体请求继续走该用户的 VPS 路径。

## 边界与验收

- 仍共享 20 秒总响应头预算、10 秒单次响应头上限、9 次总回源预算、最多 5 次重定向。响应头计时器不终止已开始的长视频流。
- 自动回退与 Cron 健康检查是两套机制；本轮保留两版各自原 Cron，不改写线路模式，公开 API 可用也不代表真实登录／播放可用。
- 共享请求体工具的未知长度有界读取是显式 opt-in；两版仅在配置完整、白名单 POST 时使用。测试编译产物使用唯一文件名，避免并行测试时的截断／导入冲突。
- 新增 Node 策略／代理回归与真实 workerd 合成验证，覆盖 401/403/451、POST 字节一致性、未知／超大请求体、取消、原鉴权错误保留、冷却／并发恢复、签名／Range、媒体跳转、私网／降级／跳转上限、VPS 配额和写请求不重放。
- 自动测试不使用生产凭据，不播放用户媒体；真实服的登录、起播、拖动、长播仍需发布后由用户验收。
